# datasource-anim-ik-samples

A Godot project of inverse-kinematics test cases: rigs, avatars and scenes for checking IK solvers.

## What it is for

The cases cover bone chains, arms and full avatars, with a retargeting demo scene, so an IK solver can be checked against the same rigs each time.

## Run

    godot --path .
